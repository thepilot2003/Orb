Organic Notch Wrapping

Seamlessly hugs the physical notch with fluid spring animations. Includes notch fine-tuning offsets for perfect pixel alignment on every MacBook model.

🎤

Real-Time Karaoke Lyrics

Synchronized lyric stream below the notch in compact mode and full Apple Music-style character glow illumination in the expanded island with vocal offset tuning.

🎛️

Dead-Center Controls

Mathematically balanced playback controls with quick-favorite star and interactive queue drawers on the flanks for effortless music control.

📅

Interactive Calendar Strip

Clickable week view that filters scheduled events, highlights meeting countdowns, and opens Apple Calendar directly to any event with one click.

🪟

Lock Screen Media Widget

Translucent floating glass player directly on your macOS Lock Screen and multi-space desktop using native SkyLight window server layers.

⚡

Ultra-Low Battery Footprint

Engineered in pure SwiftUI and Metal with debounced event loops. Consumes < 0.2% idle CPU to ensure all-day battery performance.
